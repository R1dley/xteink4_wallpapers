You can use the download.py script to batch download all the images from the [Pokedex Generator](https://basvanderploeg.nl/xteink/pokemon/).


##Prerequisites
1. Ensure you have python installed.
2. Create and activate a virtual environment:
```python3 -m vent venv```
```source venv/bin/activate```
3. Install playwright (pip install playwright).
4. Install the required browser binaries (playwright install chromium).
